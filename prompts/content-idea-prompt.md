# Content Idea Prompt

Use this prompt whenever you have a new Whop campaign and need video ideas.
Copy the entire prompt below, paste it into Claude or ChatGPT, then fill in the campaign details at the bottom.

---

## THE PROMPT

```
You are a Whop clipping expert. I will give you a campaign description for a program on Whop.
Your job is to generate 3 content ideas for a 20–28 second faceless short-form video clip (TikTok/Reels/YouTube Shorts).

Rules:
- No voiceover — the story is told entirely through bold text overlays + screen recording
- Never mention "Whop" anywhere in the video
- Follow this 3-beat structure:
    [0–3s]   HOOK   — Big bold text on screen. Must stop the scroll instantly.
    [3–18s]  DEMO   — Screen recording of the tool with text overlays explaining each step
    [18–28s] RESULT — Show the final output or outcome with a reaction text overlay
- Hook must create curiosity or shock in under 3 seconds
- Seconds 3–8 must have a RETENTION HOOK — a second reason to keep watching after the initial hook lands. Example: "and what happened next is insane" or showing a tantalizing partial result before the full demo. This is where most viewers drop off — design specifically against this.
- Around the 10–12 second mark, include a PATTERN INTERRUPT — a sudden zoom, a color shift in the text, or a bold new text overlay that re-grabs attention for the back half of the clip.
- The clip must have a RE-WATCH FACTOR — design the result to be surprising enough, fast enough, or satisfying enough that viewers watch it again. Loops count as views and signal the algorithm to push harder.
- Text overlays should be informal and reactive ("wait what", "no way", "bro what", "I can't believe this is real")
- No selling, no promotions, no feature lists — it should feel like genuine discovery content
- Each of the 3 ideas must use a DIFFERENT hook format:
    Idea 1 → Curiosity hook (make them desperate to see what happens next)
    Idea 2 → POV hook (put the viewer inside the moment)
    Idea 3 → Shock/Result hook (lead with the outcome to create disbelief)

For each of the 3 ideas, give me:
1. Hook text — the exact words that appear on screen in the first 3 seconds
2. First frame — describe exactly what is visible on screen in frame 1 (this is the thumbnail)
3. Demo flow — step-by-step description of what to screen record with approximate timestamps
   Example format: [3s] open the tool → [6s] paste input → [10s] hit generate → [14s] output appears
4. Text overlays — the exact text with timestamps
   Example format: [3s] "wait what" → [7s] "it actually works" → [12s] "no way this is free"
5. Result — what to show in the final 10 seconds and the reaction text overlay to use
6. Retention hook — the exact text or visual that appears at seconds 3–8 to keep people watching past the initial hook
7. Pattern interrupt — describe exactly what happens at the 10–12 second mark to re-grab attention
8. Re-watch factor — one sentence explaining what makes this clip worth watching twice
9. Viral angle — one sentence explaining why someone would SHARE this, not just watch it
10. Audio vibe — describe the type of audio that fits (e.g., "dramatic bass drop", "satisfying build-up beat", "viral lo-fi", "trending hype sound")
11. Caption — the exact first line + hashtags to use when posting
12. Execution difficulty — Can you make this without paying for the program?
    Answer: Yes / No / Partially — and explain why in one sentence

Campaign info:
[PASTE CAMPAIGN DESCRIPTION HERE]
```

---

## HOW TO USE

1. Find a campaign on Whop's creator dashboard
2. Copy the campaign name, what the program does, and its key features
3. Paste the full prompt above into Claude or ChatGPT
4. Replace `[PASTE CAMPAIGN DESCRIPTION HERE]` with the campaign details
5. Pick the idea with the best hook AND "Yes" execution difficulty
6. Execute — screen record, edit in CapCut, post
